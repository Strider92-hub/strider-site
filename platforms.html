Platform support

What is built, what each platform has yet to approve, and what no tool can do. Last updated 15 September 2026.

Strider is not yet open for public sign-up. All five platforms are built and publishing — that part is done. What is not done is the approval each platform runs before it will let an app connect accounts other than its developer’s own. YouTube and X are through. TikTok, Facebook and Instagram are not. This page keeps those two things in separate columns, because a support page is worth nothing if it blurs we have built it into you can use it.

Publishing to each platform

“Built” is a claim about real posts. Every row above has published and scheduled real video against that platform’s live API from the live server — not in a test, and not as a mock.

Not built yet

One feature described elsewhere on this site is still to come: posting the first comment automatically. It is not built on any platform yet. When it arrives it will not be available everywhere — YouTube and TikTok do not permit an outside tool to post a comment at all, so it can only ever work on Facebook, Instagram and X.

Why "the timing has to come from Strider" matters. YouTube and Facebook accept a future time and publish it themselves, so a scheduled post goes out whether or not anything else is running. Instagram, TikTok and X do not offer that at all — something has to be awake and send the post at the moment it is due. That difference is the reason Strider is being built as a hosted service rather than something that runs on your own computer.
